# JDR-Axolotl
Une application de gestion de Jeu de Rôle permettant entre autre de créer des maps, de les utiliser et de créer des fiches de personnages.

## Fonctionnel :
Bientôt
## En développement :
- Création de Map:
  - traçage des murs

## Fonctionnalité à venir :
- Création de Map:
  - Design du sol
  - Sauvegarde et chargement des maps (probablement en json)
  - Placement d'objet et de décoration sur la map
  - Lien entre différentes maps
  - fenêtre de création/importation de texture
- Utilisation de Map :
  - Import de token/personnages (plus tard liés aux fiches de persos)
  - Déplacement des Token et objets
  - Effets visuels (feu, zone d'effet, etc...)
  - Mode en ligne ?
- Création de fiches de personnage/modèle de fiches
- Changement des thèmes
- Plus à venir ?
